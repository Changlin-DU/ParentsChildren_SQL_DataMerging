# Figures

This directory contains the figures generated by `code/03_estimate_ige.py`.

| File | Description |
|---|---|
| `ige_comparison.png` | Compares the single-year and multi-year IGE estimates with 95% confidence intervals |
| `ige_by_age_group.png` | Compares single-year and multi-year IGE estimates across three child age groups |

Both figures use the common regression sample of 3,167 children ages 25–55. Parent-child pairs assigned to the same family unit are excluded.

To recreate the figures, run the analysis scripts from the repository root:

```bash
python code/01_prepare_data.py
python code/02_match_parents_children_sql.py
python code/03_estimate_ige.py
```

The PNG files are replaced each time `03_estimate_ige.py` runs. They should not be edited manually.
