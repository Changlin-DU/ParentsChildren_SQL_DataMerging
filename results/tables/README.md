# Tables

This directory contains summary tables generated by the analysis scripts.

| File | Created by | Description |
|---|---|---|
| `matching_summary.csv` | `02_match_parents_children_sql.py` | Counts of matched children, mothers, fathers, and usable income observations |
| `ige_sample_summary.csv` | `03_estimate_ige.py` | Sample counts after the age, income, and household restrictions |
| `ige_regression_results.csv` | `03_estimate_ige.py` | Single-year, multi-year, and rank-rank regression estimates |
| `ige_age_group_results.csv` | `03_estimate_ige.py` | IGE estimates by child age group and income measure |

To recreate all tables, run:

```bash
python code/01_prepare_data.py
python code/02_match_parents_children_sql.py
python code/03_estimate_ige.py
```

The CSV files are generated directly by the code and should not be edited manually.
