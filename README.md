# Matching Parents and Children with SQL in Python

This project uses SQL inside Python to match parents and children in longitudinal PSID data. After constructing the parent-child sample, I compare intergenerational income elasticity (IGE) estimated with single-year income and income averaged across 2020 and 2022.

The analysis was completed in an RStudio project using a Python virtual environment and DuckDB.

### Code

- `00_check_duckdb.py` checks that Python, pandas, and DuckDB are working.
- `01_prepare_data.py` reads the two source files and creates standardized DuckDB tables.
- `02_match_parents_children_sql.py` uses SQL joins to match children with their biological mothers and fathers.
- `03_estimate_ige.py` constructs the analysis sample, estimates the regressions, and generates the final tables and figures.

### Data

The `data/raw/` directory should contain:

```text
blogpost6_parent_child_2021_2023.xlsx
parent_identification_2023.txt
```

These are course-provided extracts from the Panel Study of Income Dynamics (PSID). The raw files are not tracked by Git and must be placed in this directory before running the code.

The main identifiers are:

| Person | 1968 interview number | Person number |
|---|---|---|
| Individual file | `ER30001` | `ER30002` |
| Child | `PID2` | `PID3` |
| Biological mother | `PID4` | `PID5` |
| Biological father | `PID23` | `PID24` |

The two fields in each row form a permanent person identifier. The processed datasets created by the scripts are saved in `data/processed/`.

### Results

The `results/tables/` directory contains the matching summary, sample counts, and regression estimates. The `results/figures/` directory contains:

- `ige_comparison.png`
- `ige_by_age_group.png`

These outputs are generated by the code rather than entered manually.

## Reproducing the analysis

The project was run with Python 3.12.5.

Create and activate a virtual environment:

```bash
python -m venv .venv
source .venv/bin/activate
```

Install the required packages:

```bash
python -m pip install -r requirements.txt
```

Run the scripts from the repository root in order:

```bash
python code/00_check_duckdb.py
python code/01_prepare_data.py
python code/02_match_parents_children_sql.py
python code/03_estimate_ige.py
```

The scripts use project-relative paths, so no local absolute paths need to be changed.

## Analysis choices

The SQL workflow uses `SELECT`, `INNER JOIN`, `UNION ALL`, `GROUP BY`, and aggregation to construct the parent-child sample. When both parents are available, their family incomes are averaged.

The regression sample includes children ages 25–55 with positive income who live in a different family unit from the matched parent. The same 3,167 observations are used for the single-year and multi-year specifications.

The estimated IGE is:

| Income measure | Estimate |
|---|---:|
| 2022 income | 0.275 |
| Average of 2020 and 2022 income | 0.305 |

The higher multi-year estimate is consistent with the idea that income observed in one year contains temporary variation and may be a less reliable measure of long-run economic status. The optional multi-year rank-rank estimate is 0.313.

These estimates describe associations in the matched sample and should not be interpreted as causal effects.
